## 一、项目全貌

**Valorant 枪皮/挂饰模型转换工作流**

```
Blender（建模/贴图/导出） → UE（材质自动配置/预览地图生成）
```

两端解耦，靠 **文件系统（资产路径）** 和 **命名约定** 通信，无网络调用。

## 三、核心数据流

```
[Blender] 导出 → /Game/Gun/{skin}/  和  /Game/Charm/
                        │
                        ▼  auto_material_watcher 每 tick 扫描资产数
                 （防抖 3s，冷却 3s）
                        │
                        ▼  调 batch_material_setup.py
                 （扫 /Game/ → 修压缩 → 建 MI_ → 换 Mesh 材质槽）
                        │
                        ▼  finally 里：若 overview_running → 倒计时 5s
                        │
                        ▼  调 create_overview.py
                 （建 L_{skin}_Overview 关卡、删地板、加后期盒、Y 轴排列枪身、配件/弹匣 attach）
```

**关键：`create_overview.py` 会新建关卡（产生大量新资产），必须抑制材质监听避免死循环** —— 已有双保险（60s 内部冷却 + 180s `suppress_auto_material`）。

- `RE_MAGAZINE`：`^(?:GN|EQ)_({gun})_Magazine(?:_|$)`
- `RE_BODY`：`^(?:GN|EQ)_({gun})(?:_|$)`

## 六、`auto_material_watcher` 对外接口（契约）

**材质监听**

- `start()` / `stop()` / `toggle()` / `is_running()`
- `run_once()` — 手动执行一次材质脚本
- `suppress(seconds)` — 临时抑制自动触发

**预览地图监听**

- `start_overview()` / `stop_overview()` / `toggle_overview()` / `is_overview_running()`
- `run_overview_once()` — 手动执行一次预览地图
- `suppress_overview(seconds)`

**通用**

- `status()` — 打印双通道状态

**内部状态字典**：`sys.modules["_auto_material_watcher_state"]` —— 保证跨 `exec` 调用持久化（UE 每次 `Execute Python Command` 都是新命名空间，所以必须存 `sys.modules`）。
